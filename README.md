# Continuous Presence

[OpenHanako](https://github.com/liliMozi/openhanako) 插件。给 AI 助手一种「持续存在感」——在后台默默扫描历史会话，构建经验索引，让助手在对话中能主动回想起「之前处理过类似问题时的经验和教训」，而不是每次对话都从零开始。

## 痛点

每次和 AI 对话都是一次全新开始。它不记得：

- 你昨天教过它的东西
- 上次在这个话题上踩过什么坑
- 过去用过什么工具组合来解决类似问题

Continuous Presence 补的就是这个缺口——**它不是让 AI 记住对话内容，而是让 AI 记住自己的经验曲线。**

## 与 Hanako 记忆系统的关系

Hanako 内置的**记忆系统**（Memory）和这个插件是互补关系，不是替代关系：

| | 记忆系统（Memory） | Continuous Presence |
|---|---|---|
| **存储什么** | 关于用户和世界的事实——你的偏好、重要信息、关键结论 | AI 自身的经验——处理过什么类型的问题、用了哪些工具、踩过什么坑 |
| **谁来写入** | AI 在对话中判断为重要后写入，或用户主动要求记住 | 插件自动从历史会话中提取，无需人工标记 |
| **谁来读取** | AI 在对话开始时自动加载，或通过 search_memory 主动查询 | AI 在感觉到「之前遇到过类似问题」时主动调用 recall-context |
| **知识类型** | 陈述性记忆——「知道什么」 | 程序性/经验性记忆——「做过什么、怎么做的」 |
| **数据来源** | 用户告知、AI 推断 | 历史会话文件中的结构化日志（工具调用、错误、纠正） |

简单来说：**记忆系统让 AI 知道关于你的事；Continuous Presence 让 AI 知道关于自己的事。**

两者共同作用时，AI 既记得你的偏好，也记得自己过去怎么帮你解决问题的——这才是完整的「持续存在」。

## 原理

直接读取 Hanako 本地保存的 `.jsonl` 会话文件（`~/.hanako/agents/hanako/sessions/`），解析每轮对话的结构化数据：

- 提取话题关键词、使用的工具
- 记录工具调用中的错误（踩坑）和调用顺序
- 检测用户纠正行为
- 构建轻量本地索引（`plugin-data/continuous-presence/index.json`）
- **挖掘工作流模式**：分析工具调用序列，发现反复出现的组合和流程
- **工具-错误关联**：记录每个工具最常见的报错

索引只存元数据，不存对话原文。

## 工作流模式

Continuous Presence 不仅记录「用过什么工具」，还能发现**工具调用的规律**。

通过分析历史会话中工具调用的先后顺序，自动挖掘反复出现的**工作流模式**。采用双轨分析：

- **原始工具名**：精确匹配，发现具体流程（如 `web_search → web_fetch → install_skill`）
- **分类工具名**：将同类工具归组后分析，发现更高层次的抽象模式（如 `file_ops → file_ops → write` 覆盖所有「执行命令→写文件」的变体）

模式按频率、长度、关联话题和关联错误综合评分，去重后保留最有价值的 Top 30。

同时记录**工具-错误关联**——每个工具最常见的问题是什么，让 AI 在复用模式时知道哪里容易踩坑。

## 提供的工具

| 工具 | 说明 |
|---|---|
| `continuous-presence_recall-context` | 查询过去对话经验。输入话题，返回相关历史会话及其摘要、工具使用、踩坑记录，以及相关工作流模式 |
| `continuous-presence_session-summary` | 查看今日/本周/本月会话概览，包含统计数据和会话列表，以及常见工作流模式排名 |

两个工具**只在你或 AI 主动调用时才生效**，不做未经同意的上下文注入。

## 安装

1. 将 `continuous-presence/` 整个文件夹放入 `~/.hanako/plugins/`
2. 在设置 → 插件中开启「允许全插件访问」
3. 重启 Hanako

## 权限说明

本插件需要 `full-access` 权限，因为：
- 使用 `index.js` 生命周期，后台常驻扫描会话文件
- 使用 `bus.handle()` 注册事件处理器
- 使用 `registerTool()` 动态注册工具

## 数据安全

- **所有数据本地处理**，不发送任何网络请求
- 只读取会话文件的元数据（话题、工具名、错误记录），不存储对话原文
- 索引文件位于 `plugin-data/continuous-presence/index.json`，属于你的私人数据
- 插件本身不包含任何个人信息，可放心开源
